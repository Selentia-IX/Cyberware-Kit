# Cyberware Kit

This folder is the built web app for **Cyberware Kit**, a site where you design custom Cyberpunk 2077 cyberware in a GUI and download it as a ready-to-install mod.


> Experimental. Test what you make in game before you publish it.

## What you can do on the site

- Pick a slot on the body map and make a piece: name, description, rarity tiers, price, capacity cost, armor, stats, abilities and a custom icon.
- See the in-game tooltip for every tier while you edit. Mistakes are listed under the body map, and the effect at fault is highlighted.
- Share a build as a link or a key. The key holds only settings, never pictures.
- Download the mod as a zip: TweakXL tweaks, an ArchiveXL archive with names, descriptions and icons, and a text file of CET `Game.AddToInventory` commands.

Everything runs in your browser. Nothing is uploaded to a server.

## Playing a downloaded mod

Players need [RED4ext](https://www.nexusmods.com/cyberpunk2077/mods/2380), [TweakXL](https://www.nexusmods.com/cyberpunk2077/mods/4197) and [ArchiveXL](https://www.nexusmods.com/cyberpunk2077/mods/4198).

[redscript](https://www.nexusmods.com/cyberpunk2077/mods/1511) and [Codeware](https://www.nexusmods.com/cyberpunk2077/mods/7780) are optional: they load a backup copy of the names and descriptions; and if your cyberware uses scripts.

Install the zip with Vortex or MO2, or extract it into the game folder (the one that holds `bin` and `r6`).
